# 🕺 Floss App

Welcome to the **Floss App** — a fun and simple interactive web app that plays a floss dance GIF and music after a few button presses. Just keep clicking **Free Robucks**... you know you want to 😄

---

## 💡 Features

- 🎵 Plays floss music
- 🕺 Displays floss dance GIF
- 🔘 Fun "Free Robucks" button progression
- 📱 Fully responsive for mobile and desktop
- 💻 Built using HTML, CSS, JavaScript, and jQuery

---

## 🚀 Getting Started

To run the app locally:

1. Clone or download this repository.
2. Ensure all files are in the same directory:
   - `index.html`
   - `index.css`
   - `index.js`
   - `floss.gif`
   - `floss.mp3`
3. Open `index.html` in your browser.
4. Click the buttons and enjoy the floss party!
